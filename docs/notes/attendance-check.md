# 출석부 점검 (실험실, attendance-check.html)

## 첫 버전 (2026-10-23)
- 실험실(`lab.html` LAB_ITEMS, state try)에서만 링크. 관리자 + 승인 계정만.
- ① 나이스 출석부(주간) PDF: pdf.js 글자 위치로 직접 판독(AI 안 씀). PDF가 가로로 돌려 저장돼 있어 `pdfjsLib.Util.transform(viewport.transform, item.transform)`으로 화면 좌표를 써야 함.
  날짜 머리 "04월13일(월)", 날짜마다 `조`(조회)·1~10교시·`마`(마감) 칸 → 간격 = (마감−조회)/11. 그날 출결 기호는 **마감 칸**, 교시 칸의 `/`(지각 등으로 빠진 교시)·`Ø`(결과 교시).
  범례(나이스): 결석 ♡♥▲△ / 지각 ＃X≠◁ / 조퇴 ＠◎∽▷ / 결과 ☆◇=▽ (질병·미인정·기타·출석인정 순). 전각 ＃＠는 정규화.
  학생 줄은 "12 이영민" 한 덩어리로 나옴(번호+이름 따로인 경우도 처리).
- ② 종이 출석부 사진: Edge Function `attendance-photo-read`(v1, verify_jwt:false, 기본 sonnet·ai_models slug, Gemini 폴백, structured output json_schema, 1인 하루 40회, 사진 저장 안 함).
  브라우저에서 긴 변 2576px로 줄이고, 긴 변이 3000px 넘으면 긴 쪽을 53%씩 두 조각으로 나눠 보냄. 나이스에서 읽은 번호·이름·날짜를 힌트로.
  종이 기호(교사 안내): ○질병 ◎미인정 □기타 △출석인정, 기호 위 / = 지각, X = 조퇴, 교시 칸에만 = 결과.
- ③ 대조: 학생·날짜별로 (종류+사유) 맞추기 → 일치 / 사유 다름 / 나이스에만 / 출석부에만, 결과는 교시도 비교, AI가 흐리다고 한 건 "확인 필요". 줄 누르면 사진 크게, 엑셀 저장.
- 실제 AI 판독 정확도는 아직 검증 전(샌드박스에서 AI 서버 접근 불가) — 실제 자료로 확인 필요.

## 한 쪽씩 사진·사유 파일 (2026-10-23)
- 사진은 펼친 두 쪽이든 한 쪽씩이든, 방향 상관없이. 대조는 사진 단위가 아니라 **날짜 단위로 합침**: 각 사진의 AI `dates`(실제로 보이는 요일 머리)를 그 사진이 덮는 날짜로 보고, 여러 사진이 덮은 날짜만 비교(안 찍은 날의 나이스 기록은 '나이스에만'으로 잡지 않음). 날짜를 못 읽으면 주를 직접 고르게(`weekManual`).
- attendance-photo-read v2: 프롬프트에 한 쪽 사진·아무 방향, dates에는 보이는 날짜만(안 보이면 0).
- ①-2 사유 파일(선택, xlsx/csv): 머리글로 번호(또는 성명→번호)·일자·사유(·구분) 열을 찾아 `REASONS['번호|MM-DD']` → 나이스 칸에 "사유: …". 실제 나이스 사유 파일 형식은 아직 못 봄 — 예시 받으면 맞출 것(PDF면 따로 판독 필요).

## 나이스 출석부 받는 곳 · 엑셀 판독 (2026-10-23)
- **받는 곳(사용자 안내용)**: 나이스 → 학급담임 → 출결관리 → **출석부출력(담임용)** → 주 선택 → 💾 저장 버튼 → 엑셀 또는 PDF. 페이지 ① 안내 문구에 넣어 둠.
- 두 형식 내용은 같음(주간 1장, 사유 없음). **엑셀을 권장**: 칸마다 머리글(`조회`/`1`~`10`/`마감`, 줄바꿈·공백 섞임 → 공백 제거해 비교)이 있어 위치 추정이 필요 없음. 날짜 머리 줄 "09월28일(월)"(병합 셀 시작 열) 기준으로 그 오른쪽 머리글 칸을 그 날짜로 배정. 학생 줄 = 0열 번호, 1열 이름.
- `parseNeisSheet(rows)`(엑셀) / `parseNeisItems(items)`(PDF) → 같은 모양, `mergeNeis`로 여러 파일 합침.
- 실제 표시가 있는 나이스 엑셀은 아직 못 봄(받은 예시 주는 표시 0건) — 표시를 넣은 사본으로만 검증. 사유는 두 파일 모두 없음 → ①-2 사유 파일 형식 확인 필요.

## 세 자료 점검 (2026-10-23)
- 자료: ① 나이스 출석부(주간, 선택) ② **나이스 월별 출결현황**(엑셀) ③ 종이 출석부 사진. **필수는 ②+③**(①은 나이스 내부 교차 확인용).
- **월별 출결현황 받는 곳(사용자 안내용)**: 나이스 → 학급담임 → 출결현황및통계 → 학급별출결현황 → **월별 출결현황** → 엑셀 저장. 열: 일자("2026.05.13.(수)")·번호·성명·출결구분("출석인정지각")·결시교시("조회(Ø),1교시(Ø),…,종례,")·사유. 같은 학생·같은 값이 **병합 셀**이라 `!merges`를 위 값으로 채운 뒤 읽음(`parseMonthlySheet`). PDF판은 병합 때문에 지저분해 엑셀만 받음.
- attendance-photo-read v3: 스키마에 `notes`(특기사항: 요일·번호들·원문)·`unsigned`(교사 확인 빈 교시, 조회=0, 수업 없었을 수 있으면 low) 추가.
- 점검 항목: 나이스 출석부↔출결현황(종류·사유·교시), 종이↔나이스(출결현황 우선), 종이 특기사항 글↔종이 기호(`kindOfText`), 사유 글↔사유 종류(`WHY_WORDS` 낱말로 질병/출석인정/미인정 어울림 — 다른 쪽 낱말만 있으면 "사유 확인"), 나이스 사유 빈칸, 서명 빈 교시. 한 날짜를 두 자료 이상이 덮을 때만 비교.
- 실제 표시 있는 출석부 사진·나이스 출석부로는 아직 미검증(가상 데이터로 흐름만 확인).

## 실험실 공개 범위 (2026-10-23)
- 실험실(lab.html)·출석부 점검을 관리자 전용 → **로그인·승인된 회원 누구나**로. KS_MENU의 admin 플래그 제거, 두 페이지 게이트를 approved만 확인. attendance-photo-read도 approved만 확인(하루 40회 제한).

## 나이스 출석부 입력 제거 · 요일별 교시 · 바로 촬영 (2026-10-23)
- 사용자 결정: 입력은 **① 월별 출결현황(엑셀) + ② 종이 출석부 사진**만. 나이스 출석부(주간) 판독 코드(pdf.js 좌표·엑셀 머리글)는 페이지에서 뺐음 — 위 기록과 git 기록에 남아 있음.
- 점검은 사진에 찍힌 날짜만. 학생 명단·연도는 월별 출결현황에서.
- 이 학교 수업 교시: 월 6, 화 6(가끔 7), 수·목 7, 금 6 → `LAST_PERIOD`. 그 뒤 교시의 빈 서명은 문제 아님(제외), 화 7교시는 "?"(수업 없었을 수 있음).
- "📷 바로 촬영" 버튼: `<input type=file accept="image/*" capture="environment">`(휴대폰에서 카메라 바로 열림, 한 번에 한 장).
