# 학생 시간표 (`student-timetable.html`)

## 처음 만듦 (2026-10)
- 표 `student_timetables` (year, semester, grade, class_no, no) — `courses` [{s 과목, sec 수강반, fg 파일 학년}], `grid` {월:{"1":{s, sec, r, t}}}, `issues`, `manual`(엑셀로 직접 고친 학생).
  select는 승인 회원, 쓰기는 RPC `stt_save_courses` / `stt_save_grids` (`verify_edit_role(p_password, '교육과정')`). 둘 다 upsert만 함(DELETE 없음 — MCP 타임아웃 피함).
- 만드는 규칙(엔진은 페이지 안 `sttStudentGrid`, 페이지에서 계산):
  - 알파벳 없는 과목 = 그 교실 반(206 → 2-6) 공통 수업. `직업반`은 뺌.
  - 알파벳(A~H) = 같은 학년 안의 시간 블록. 학년 블록 = 그 학년 교실(2xx)에서 그 알파벳 수업이 열리는 시간 →
    다른 학년의 같은 과목·같은 알파벳(인공지능기초D 2·3학년)을 시간으로 가려냄.
  - 숫자까지 붙은 반(B1~B5, G1·G2, A1·A2): 내 교실 쪽 → 같은 알파벳·숫자의 다른 과목이 내 교실인 쪽(미적분B1 302 ↔ 확률과통계B1) →
    시간이 같으면 교실 같이 표시 / 1시간+2시간 나눠 맡기면 모두 / 그래도 모르면 "확인 필요"(수강 배정 칸에 B1처럼 적으면 해결).
  - 금 5·6교시 창체, 화 7교시 공강(`화공강` → "공강"). 금 6교시는 5교시 복사(다른 페이지와 같은 규칙).
  - 이름 맞추기: 공백·가운뎃점 제거, Ⅰ/Ⅱ→1/2 (물리학Ⅱ ↔ 물리학2D, 한문Ⅱ ↔ 한문2H).
- 수강 배정 파일: 나이스 "배정내역" 시트(머리글 두 줄: 위 학번·이름 + "2학기[택4]" 묶음, 아래 과목명). 묶음에 "학기"가 있으면 고른 학기만 읽음.
  파일 학년(학번 다수) 기준으로 그 학년 과목만 바꾸고, 다른 학년 과목(fg)은 남김(2학년이 3학년 과목 듣는 경우).
- 저장 전에는 보기 화면이 지금 교사 시간표로 계산한 "미리 보기". 1학년은 수강 배정 없이 반 공통으로 나옴.
- 엑셀: 학생 한 줄(월1~금7, "과목 (교실)") 받기·올리기 → 바뀐 학생만 `manual=true`로 저장, 다시 만들 때 건너뜀(체크하면 포함).
- 학생에게 보내기: `student_portal_items.kind`에 `timetable` 추가. 보낼 때 학생마다 `targets.payload = {tt: grid, label}`(보낼 때 모습 그대로).
  학생 화면(`student.html`·포털 미리보기 같은 코드)에 표로 그림.
- 받는 학생 고르기에 "수강반으로 고르기" 탭(포털) / "수강반으로 추가" 줄(설문 대상 명단) — `courses`로 과목·수강반 학생을 고름.
- 자료 한번에 관리: 링크 카드 `stt`(이번 학기 저장 인원 표시), 업무 역할 '교육과정' 설명에 추가.
- 실제 수강 배정 엑셀(학생 실명)은 저장소에 커밋하지 말 것.

## 전학생 학번 맞추기
- 배정 파일 학번이 명렬에 없거나 다른 학생이면, 같은 이름의 명렬 학생이 한 명뿐이고 파일에 그 학번이 없을 때 그 학생으로 맞춤(예: 3학년 전학생이 옛 학번 2xxxx로 들어온 경우). 미리 보기에 "이름으로 맞춘 학생"으로 표시.

## 미리 보기 ↔ 저장 혼동 (2026-10)
- 사용자가 "시간표가 만들어져 있는데 학생 페이지에서 없다고 나온다" → DB `student_timetables` 0행(수강 배정도 0). 학생 시간표 화면은 저장 전에도 교사 시간표로 계산한 미리 보기를 보여 줘서 착각.
- 저장 전이면 학생 시간표 화면에 빨간 안내(① 수강 배정 저장 → ② 시간표 만들기), 학생 페이지 시간표 고르기에 "저장 안 했을 수 있어요 + 학생 시간표 열기" 안내.

## 지우기·확인할 학생 (2026-10)
- RPC `stt_clear(p_password, p_year, p_sem, p_what 'courses'|'grids')` — DELETE 대신 UPDATE로 비움(교육과정 역할). ①에 "올린 수강 배정 지우기", ②에 "만든 시간표 지우기".
- ② 아래 `#genCheck`: 수강 배정 없는 2·3학년(직업반 표시) + 지금 만들면 확인 필요가 나오는 학생을 학번·이름·비고·내용 표로(접힘). 만들기 결과의 확인 필요도 전부 펼쳐 보기.
- 실제 2026-2: 수강 배정 없는 11명은 모두 3학년 직업반(전출·자퇴 제외) — 정상.
