# 학기 업무 흐름 체크리스트 (`work-flow.html`, 실험실)

## 처음 만듦 (2026-10-23)
- 원본: 사용자의 학교 메신저(2021~2026) 정리본 "월별 업무" → 달별 항목 107개(담임 41)로 큐레이션해 DB에 넣음. **내용은 DB에만**(공개 저장소라 HTML에 넣지 않음).
- 테이블 `work_flow_items`(yorder 0=새 학년 준비(2월)·1=3월…10=12월·11=1월·12=학년말(2월), month, phase, sort, title, detail, homeroom, who, monthly, form_hint) — 승인 회원 select, 관리자만 쓰기.
  `work_flow_checks`(user_id, item_id, school_year) — 본인 것만. 학년도는 3월 시작(2월 15일부터 새 학년 준비로 봄).
- 화면: 달 칩(진행 n/m, 지금 달 강조·자동 스크롤) → 달 카드(단계 배지·진행 막대·항목). 담임 업무는 제목 앞 분홍 점, 매월 하는 일은 "매월" 태그(3월에 한 번만 둠), `form_hint`가 있으면 "서식 보기 →"(form-board ?q=).
  "담임 업무 숨기기"·"끝낸 일 숨기기"는 localStorage(`ks_workflow_prefs`). 관리자는 "항목 편집"으로 추가·수정·삭제(모달).

## 메신저 전체로 다시 만듦 + 주차별 (2026-10-23)
- 사용자 요청: 분류 추출본(357개)이 아니라 **메신저 전체**(16,821건 중 잡담·부고·축하·짧은 1:1 대화 뺀 업무 메시지 약 8,200건)로. 기간(달, 바쁜 달은 1~15일/16일~)마다 모든 해를 모아 15묶음 병렬 → 603개 → 병합 150개(담임 53, 매월 7). 일회성·한시적·아주 개인적인 일, 특정 장학재단·특정 프로그램은 빼거나 일반화.
- `work_flow_items`에 `day_from`/`day_to`/`timing`(메시지 날짜 기반) 추가. 화면은 달 안을 **주차별**(1~7 첫째·8~14 둘째·15~21 셋째·22~ 넷째, `day_from` 기준)로 묶고, 여러 주에 걸치면 "~셋째 주" 배지, 매월 일은 "매월 하는 일" 묶음 + timing 배지. 지금 달·이번 주 강조(이번 주 시작 일이 없으면 빈 자리 + 이어지는 일 수 안내).
- 예전 107개는 MCP에서 DELETE가 타임아웃이라 `retired=true`로 숨김(select 정책 `and not retired`). 나중에 SQL Editor에서 `delete from work_flow_items where retired;` 해도 됨.

## 위쪽 고정·달별 접기
- `.wf-sticky`(학년도·보기 줄 + 달 칩)를 sticky top:0. 달 제목(`data-fold`) 누르면 접기·펼치기, "모두 접기/펼치기", 접은 달은 localStorage `ks_workflow_prefs.folded`에 기억. 달 칩을 누르면 그 달을 펼치고 고정 줄 높이만큼 띄워 스크롤.
