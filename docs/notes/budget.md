# 예산 지출 관리 (`budget.html`, 실험실)

## 처음 만듦 (2026-10)
- 선생님이 쓰던 예산 엑셀(시트 "사용 내역 기록"·"사용 내역 검색"·"2026년 예산")을 거의 그대로 옮김.
- 표 `budget_items`(회계연도 year, 예산 종류 kind · 세부사업명 project · 영역 area, amount, note 비고, detail 내역(예산 계획·산출 내역), category 구분, owner_name 담당)
  / `budget_spends`(같은 세 분류 + program 프로그램명, spend_date, user_name 사용자, amount·amount_expr(계산식), note, detail, planned 예정).
- 엑셀처럼 **세 분류 이름(kind·project·area)으로** 예산과 사용 내역을 이음(id 아님). 같은 이름 예산이 여럿이면 금액을 합쳐 계산.
  예산 이름을 바꾸면 트리거 `budget_items_rename`이 같은 해 사용 내역 이름도 바꿈(같은 이름 예산이 더 남아 있으면 안 바꿈).
- 잔액 = 예산 − 쓴 돈 − 예정. 집행률 막대: 진한 색 쓴 돈, 옅은 색 예정, 100% 넘으면 빨강. 날짜가 오늘 뒤면 예정 자동 체크.
- 권한(RLS): 승인·활동 회원 모두 보기·등록. 고치기·지우기는 `budget_can_edit(created_by, 이름)` — 관리자, 만든 사람, 또는 담당(owner_name)/사용자(user_name) 이름이 나인 경우.
- 금액 칸은 계산식 허용(`50000*8*3`, `70,000x5`) — 숫자·사칙연산만 허용 후 계산.
- 엑셀 가져오기: "○○년 예산"·"사용 내역 기록" 시트의 머리글("예산 종류") 줄을 찾아 읽음. 표 아래 드롭다운용 목록(머리글 반복)·빈 줄 5개에서 멈춤.
  같은 이름·금액 예산, 같은 이름·날짜·금액·프로그램 내역은 건너뜀. 담당은 그 예산 사용 내역에 가장 많이 나온 사용자.
- 예산에 없는 이름으로 적힌 사용 내역은 예산 탭 아래 경고로 보여 줌.
- 실제 예산 엑셀(희망교실 시트에 학생 이름 있음)은 커밋하지 말 것.
