NEIS에서 받은 고사실별응시인원 원본 파일(.xls) 하나만 올리면, N응시실 / 자료 / 대기실 인쇄용 시트를 조합해서 학생별 시험 시간표 데이터를 자동으로 만들어요. 시험 시간표 페이지의 양식은 이 페이지 안에 이미 들어있어서 다른 파일이 따로 필요 없어요. 결과는 미리보기로 꼭 확인하신 뒤, 유의사항을 입력하고 다운로드하면 exam-2026-2-mid.html처럼 시험마다 다른 이름의 파일이 만들어져요 — 깃허브에 그 파일을 새로 추가한 뒤, 배포된 그 페이지를 열어서 안에 있는 "+ 이 시험 목록에 추가" 버튼을 한 번 눌러주시면 exams.html(시험 목록 페이지)에 자동으로 나타나요.

⑥ 다운로드

기존 시험 시간표 페이지의 디자인·인쇄 기능은 그대로 두고, 학생 데이터와 유의사항만 새로 교체한 파일을 이 시험 전용 이름(예: exam-2026-2-mid.html)으로 내려받아요. 이 파일에는 "+ 이 시험 목록에 추가" 버튼이 이미 들어있으니, 깃허브에 추가해 배포한 뒤 그 페이지에서 버튼만 한 번 눌러주면 exams.html(시험 목록 페이지)에 자동으로 올라가요 — exams.html 자체는 건드릴 필요 없어요.
이 페이지는 자동 계산 결과이니, 다운로드 전에 실제 학생 몇 명을 원본 파일과 직접 대조해서 확인해주세요. 특히 선택과목이 겹치는 교시(예: 여러 과목이 같은 시간에 열리는 경우)는 자동으로 해석되므로 한번 더 확인이 필요해요.
