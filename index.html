업무 링크 모음

→
📥

제출함

제목과 마감을 정해 제출함을 만들고 링크만 공유하면, 누구나 로그인 없이 파일을 낼 수 있어요.

→
🛠️

교무 업무 도구

시험 시간표·문항 배점 생성기, 메시지함, 나만의 챗봇 비서, 공지사항 작성 등 교무 업무용 도구 모음이에요.

→
📝

메모장*

날짜·시간과 함께 메모를 남기고 라벨을 붙여 검색할 수 있어요. 대시보드 위젯과 내용이 그대로 이어져요.

→
🤖

교사용 챗봇*

선생님들이 올려둔 자료를 바탕으로 질문에 답해요. 양식 파일을 요청하면 찾아서 다운로드 링크도 함께 드려요.

→
⚙️

수업용 챗봇 만들기*

학생들에게 공유할 나만의 챗봇을 만들어요. 성격과 참고 자료를 정하면 링크와 암호가 생겨요.

→
📣

할 일 요청*

다른 사람에게 업무를 배정하거나, 나에게 배정된 업무를 확인해요. 나의 페이지의 같은 블록과 완전히 연동돼요.

→
📄

문서 양식 공유*

기안문·품의문·출결 공문 같은 서식을 카테고리별로 올리고, 제목을 눌러 내용을 펼친 뒤 바로 복사해서 써요.

→
🗄️

자료실*

선생님들이 자유롭게 올리고 받아가는 공용 파일 창고예요. 폴더를 만들어 분류하고, 파일 이름을 누르면 바로 내려받아요.

→
🍜

맛집 공유지도*

지도를 클릭해 맛집 위치를 찍고 이름·종류·한줄평을 남겨요. 좋아요로 추천하고, 종류별로 필터링할 수 있어요.

→
🧳

분실물 관리

포에듀케이터 경성고 분실물 센터로 바로 이동해요. 새 창에서 열려요.
