자주 쓰는 기능

내가 고정 자주방문 기록으로 자동
전체 기능 보기

할 일 요청*

다른 사람에게 업무를 배정하거나, 나에게 배정된 업무를 확인해요. 나의 페이지의 같은 블록과 완전히 연동돼요.

→

메모장*

날짜·시간과 함께 메모를 남기고 라벨을 붙여 검색할 수 있어요. 대시보드 위젯과 내용이 그대로 이어져요.

→

나만의 챗봇 비서*

나만 쓰는 개인 비서 챗봇이에요. 자료를 올리고 대화가 계속 이어져요.

→

내가 만든 도구*

필요한 기능을 챗봇에게 말로 설명하면 바로 쓸 수 있는 작은 도구를 만들어 줘요. 고치고 공유할 수 있어요.

→

공지사항 작성*

가입한 선생님은 누구나 쓸 수 있어요. 정한 기간 동안 모든 선생님의 나의 페이지·대시보드 상단에 나타나요.

→

캘린더

한 달씩 넘겨보며 학사일정을 한눈에 확인해요. 날짜를 누르면 상세 정보로 이동.

→

주간계획

구글 드라이브 '주간계획' 폴더의 최신 문서를 AI 요약·원본·전체 목록으로 한 화면에서 봐요.

→

교사 시간표 조회·비교

선생님을 선택하면 주간 시간표를 보여주고, 여러 명을 고르면 공통 공강 시간을 찾아줘요.

→

학생 지도 당번표

정문·후문·중식·야자 담당자를 날짜별로 자동 표시. 이름 검색, 전체 일정 목록 포함.

→

오늘의 급식

나이스(NEIS) 급식 정보를 실시간으로 불러와 보여줘요. 날짜 이동 가능.

→

교실 사용 예약

요일·교시별 달력에서 빈 칸을 눌러 바로 교실을 예약해요.

→

제출함

제목과 마감을 정해 제출함을 만들고 링크만 공유하면, 누구나 로그인 없이 파일을 낼 수 있어요.

→

설문조사*

설문·투표를 만들고 링크를 공유하면, 로그인 없이도 누구나 그 링크에서 바로 응답할 수 있어요.

→

서식·양식·공용 메모*

기안문·품의문·출결 공문 같은 서식을 카테고리별로 올리고, 제목을 눌러 내용을 펼친 뒤 바로 복사해서 써요.

→

자료실*

선생님들이 자유롭게 올리고 받아가는 공용 파일 창고예요. 폴더를 만들어 분류하고, 파일 이름을 누르면 바로 내려받아요.

→

업무 링크 모음

자주 쓰는 업무 링크를 누구나 추가하고, 카테고리별로 모아보고, 검색도 할 수 있어요.

→

시험 시간표*

학년·반·학생을 선택하면 개인별 시험 과목·고사실·대기 장소가 나와요. 인쇄 가능.

→

문항 배점 생성기

총점수·총문항수·배점 개수·배점 범위를 입력하면 문항별 배점과 문항수를 자동으로 계산해줘요.

→

예상 등급 산출*

점수 일람표를 붙여넣으면 석차등급 산출 기준과 동점자 중간석차 처리 규정을 적용해 예상 등급과 등급컷을 계산해줘요.

→

모의면접 분석

모의면접을 녹음·전사하고, 문항별 답변과 선생님 메모를 바탕으로 AI가 종합 평가 보고서를 만들어줘요.

→

결석신고서*

학년·반·번호·이름·사유·기간을 입력하면 서명용 링크가 만들어져요. 학생·보호자가 로그인 없이 서명하면 담임 선생님이 확인 후 PDF로 저장·출력할 수 있어요.

→

교사용 챗봇*

선생님들이 올려둔 자료를 바탕으로 질문에 답해요. 양식 파일을 요청하면 찾아서 다운로드 링크도 함께 드려요.

→

수업용 챗봇 만들기*

학생들에게 공유할 나만의 챗봇을 만들어요. 성격과 참고 자료를 정하면 링크와 암호가 생겨요.

→

맛집 공유지도

지도를 클릭해 맛집 위치를 찍고 이름·종류·한줄평을 남겨요. 좋아요로 추천하고, 종류별로 필터링할 수 있어요.

→

분실물 관리

포에듀케이터 경성고 분실물 센터로 바로 이동해요. 새 창에서 열려요.
